# Cost Optimization Notes:

#
# 1. sentence-transformers instead of OpenAI embeddings:
#    - Cost: $0 (runs locally)
#    - vs OpenAI: ~$0.0001 per 1K tokens
#    - Savings: ~$100/month for 1M embeddings
#
# 2. DuckDB instead of BigQuery:
#    - Cost: $0 (runs locally or on your server)
#    - vs BigQuery: ~$5/TB queried
#    - Savings: ~$50/month for analytical queries
#
# 3. Redis caching:
#    - Reduces repeated embedding generations by 90%+
#    - ROI: ~$90 saved per $10 spent on Redis
